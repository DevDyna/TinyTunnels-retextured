# Tiny Tunnels API Split Tasks

The shared task list for the API split team (`api-split-team.md`). Started 2026-10-01.

**How to use it:**
- One row per task, named with its phase (`A2.3 ...`). Keep tasks small: one owner, a few files.
- **Claim** a task by putting your role in "Owner" and setting the status to `in progress`. Only edit your own rows; the lead adds and removes rows.
- **Status:** `open`, `in progress`, `blocked` (say on what, and message the lead), `review` (waiting on a QA run or the lead), `done`.
- **Done means:** it compiles, its tests pass in a QA run, its docs are updated, and the summary below says what changed, which files, and anything left (two to four lines).
